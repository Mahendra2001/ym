# Khandeshi Crunch - Banana Chips Website

A modern, responsive website for Khandeshi Crunch banana chips with animated floating chip background.

## Features
- 6 product showcase with horizontal scrolling
- Animated floating banana chips background
- Responsive design
- Smooth scroll navigation
- Modern UI with gradient effects

## Files
- `index.html` - Main website
- `style.css` - Styling and animations
- `images/` - Product images (6 chip photos)
